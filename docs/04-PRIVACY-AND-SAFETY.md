# প্রাইভেসি ও নিরাপত্তা নীতি

> **মূল নীতি:** যতটুকু দরকার, ততটুকুই। যেটুকু প্রকাশ, তার জন্য স্পষ্ট সম্মতি।

---

## ১. ডেটার শ্রেণি

| শ্রেণি | উদাহরণ | কোথায় থাকে | কে দেখে |
|---|---|---|---|
| **P0 · পাবলিক** | প্রতিষ্ঠানের নাম, ঠিকানা, অফিসিয়াল নম্বর | পাবলিক API | সবাই |
| **P1 · সম্মতিসাপেক্ষ** | ব্যক্তির নম্বর (ডাক্তার, রক্তদাতা), ছবি | আলাদা টেবিল, এনক্রিপ্টেড কলাম | সম্মতি থাকলে রিলে/প্রদর্শন |
| **P2 · অভ্যন্তরীণ** | ভেরিফায়ারের নোট, রিপোর্টের বিস্তারিত | অ্যাডমিন API | verifier+ |
| **P3 · সংবেদনশীল** | লগইন, সেশন, অডিট | এনক্রিপ্টেড, সীমিত রিটেনশন | admin (অডিটসহ) |

**কঠোর নিয়ম:** P1 কখনো সার্চ ইনডেক্সে, সাইটম্যাপে, বা পাবলিক ক্যাশে যাবে না।

---

## ২. সম্মতি ম্যাট্রিক্স

| বিষয় | সম্মতি ছাড়া | সম্মতিতে |
|---|---|---|
| প্রতিষ্ঠানের অফিসিয়াল নম্বর | ✓ দেখানো যায় | — |
| ডাক্তারের ব্যক্তিগত মোবাইল | ✗ (শুধু চেম্বার নম্বর) | ✓ |
| রক্তদাতার নম্বর | ✗ (শুধু "অনুরোধ পাঠান") | ✓ কল বাটন |
| রক্তদাতার নাম | ✗ | ✓ |
| প্রতিষ্ঠানের ছবি | ✗ | ✓ (মালিকের অনুমতি) |
| ভেরিফায়ারের নাম | ✗ | ✓ মাসিক স্বীকৃতিতে |

সম্মতি **স্পষ্ট, লিখিত বা রেকর্ডকৃত** — "সম্ভবত রাজি" নয়। অ্যাডমিন প্যানেলে প্রতি P1 এন্ট্রিতে `consent_at`, `consent_channel` থাকবে।

---

## ৩. জরুরি নির্ভুলতার নীতি

একটি ভুল অ্যাম্বুলেন্স নম্বর জীবন নিতে পারে। তাই:

1. **জরুরি ক্যাটাগরিতে যাচাই ছাড়া কিছু নেই** — এমনকি সরকারি ওয়েবসাইট থেকে নিলেও ফোনে একবার নিশ্চিত করা।
2. **অনিশ্চিত হলে দেখাও না।** "তথ্য নেই" বলা "ভুল তথ্য" দেওয়ার চেয়ে ভালো।
3. প্রতিটি জরুরি এন্ট্রিতে "শেষ যাচাই: তারিখ" দৃশ্যমান, মেয়াদ পার হলে হলুদ ব্যানার।
4. ব্যবহারকারীর রিপোর্ট ৪৮ ঘণ্টায় ট্রায়াজ; ভুয়া প্রমাণিত হলে সাথে সাথে `suspended`।

## ৪. রিটেনশন

| ডেটা | মেয়াদ | পরে |
|---|---|---|
| পাবলিক এন্ট্রি | অনির্দিষ্ট (রিভিশনসহ) | — |
| P1 নম্বর | সক্রিয় থাকা পর্যন্ত | সম্মতি প্রত্যাহারে ৩০ দিনে মুছে ফেলা |
| রিপোর্ট | ২৪ মাস | অ্যানোনিমাইজ |
| অডিট লগ | ১২ মাস | আর্কাইভ (এনক্রিপ্টেড) |
| সেশন/লগইন লগ | ৯০ দিন | মুছে ফেলা |
| অ্যানালিটিক্স | ১৪ মাস (কুকি-লেস, aggregated) | — |

## ৫. ব্যবহারকারীর অধিকার

- **দেখার:** নিজের সাবমিট করা ডেটা (রিপোর্ট, ডোনার প্রোফাইল)
- **সংশোধনের:** রিপোর্ট বাটন সব এন্ট্রিতে
- **মুছে ফেলার:** ডোনার প্রোফাইল ও রিপোর্ট — ৩০ দিনের মধ্যে কার্যকর
- **অভিযোগ:** একটি ইমেইল/ফর্ম, ৭ দিনে প্রথম উত্তর

প্রতিটি অনুরোধ অডিটে যাবে (কে, কখন, কী মুছেছে)।

## ৬. টেকডাউন

কেউ বললে "আমার নাম/নম্বর সরাও":

1. ২৪ ঘণ্টায় এন্ট্রি `suspended` (সাথে সাথে অদৃশ্য)
2. ৪৮ ঘণ্টায় সম্পূর্ণ মুছে ফেলা বা অ্যানোনিমাইজ
3. ব্যবহারকারীকে নিশ্চিতকরণ
4. কারণ ও প্রমাণ অডিটে

## ৭. নিরাপত্তা বেসলাইন

- সব ট্রাফিক HTTPS (HSTS), কুকি `Secure; HttpOnly; SameSite=Lax`
- অ্যাডমিনে **MFA বাধ্যতামূলক**; সেশন ৮ ঘণ্টা, প্রমাণিত ডিভাইস ছাড়া নতুন ডিভাইসে ইমেইল নোটিফিকেশন
- পাসওয়ার্ড argon2id; লগইনে রেট লিমিট + ধীরে ধীরে লকআউট
- সব মিউটেশনে CSRF টোকেন; পাবলিক ফর্মে Turnstile
- SQL ইনজেকশন: parameterized queries only (ORM + raw query পলিসি)
- XSS: ইউজার-জেনারেটেড সব কনটেন্ট escape; CSP `default-src 'self'`
- আপলোড: MIME স্নিফিং, ৫MB সীমা, EXIF স্ট্রিপ, আলাদা ডোমেইনে সার্ভ
- স্বয়ংক্রিয় ডিপেন্ডেন্সি অডিট + SBOM প্রতি রিলিজে

## ৮. লগে যা কখনো থাকবে না

- ফোন নম্বর, ইমেইল, পাসওয়ার্ড, টোকেন (শুধু হ্যাশ/আইডি)
- পুরো রিকোয়েস্ট বডি
- ভেরিফায়ারের ব্যক্তিগত নোট

লগ রিভিউ প্রতি মাসে একবার: `grep` চালিয়ে প্রমাণ রাখা যে PII নেই (রিলিজ চেকলিস্টের অংশ)।

## ৯. আইন ও নীতি

- বাংলাদেশের প্রযোজ্য ডেটা সুরক্ষা, সাইবার নিরাপত্তা ও ভোক্তা-সুরক্ষা আইনের সাথে সামঞ্জস্য — **লঞ্চের আগে আইনি পর্যালোচনা বাধ্যতামূলক** (এই ডকুমেন্ট আইনি পরামর্শ নয়)।
- সরকারি তথ্য ব্যবহারে উৎস উল্লেখ।
- বাণিজ্যিক ব্যবহার (বিজ্ঞাপন) শুরু হলে প্রাইভেসি নোটিশ ও সম্মতি পুনঃপর্যালোচনা।
- ডেটা কখনো বিক্রি নয়, তৃতীয় পক্ষের ট্র্যাকিং SDK নয়।
